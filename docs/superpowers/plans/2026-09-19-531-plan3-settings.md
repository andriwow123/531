# 5/3/1 App — Plan 3: Settings Hub — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Settings screen and persisted, app-wide-live settings that turn the existing engine's knobs into real controls — display density, templates (incl. enabling 5s-PRO), rest timer (config + running), theme, TM % and rounding — plus the deferred fixes Settings unblocks.

**Architecture:** A Dexie v2 `settings` singleton + `settingsRepo`; a `SettingsProvider`/`useSettings()` context as the single live source of truth; a Settings screen that edits it; Home rewired to read it (display gating + a running rest timer); CycleEnd fixed for 5s-PRO and to snapshot the current template into the next cycle.

**Tech Stack:** React 19 + TS, Dexie, Vitest. Reuse the COACH theme tokens.

**Spec:** `docs/superpowers/specs/2026-09-19-531-plan3-settings-design.md` (builds on the app design spec).

## Global Constraints

- Reuse COACH theme tokens only; Manrope; mobile-first; dark + light. `import type` for type-only; `tsc -b` clean; `npm test` green; all prior (73) tests stay green.
- Dexie change is **additive** at `version(2)` — v1 stores untouched, no data migration, existing data preserved.
- Settings changes never corrupt data; template / TM % / rounding changes are forward-looking. **Template changes take effect on the NEXT cycle** (Home builds from the cycle's snapshot).
- History is NOT gated by settings (always shows its charts/PRs). The display presets/toggles govern the **Home** screen only.
- No backup/restore, no unit switching, no trackers (deferred).

```ts
import { defaultSettings } from '../settings/schema';
import type { SettingsState } from '../settings/schema';
export type StoredSettings = SettingsState & { id: 'app' };

  get: async (): Promise<SettingsState> => {

    if (!row) return defaultSettings;
    const { id: _id, ...rest } = row;
    return { ...defaultSettings, ...rest };
  },

};
```

### Task 4: Rest-timer pure reducer

**Files:** Create `src/settings/timer.ts`, `src/settings/timer.test.ts`.

**Interfaces:**
```ts
export interface TimerState { secondsLeft: number; running: boolean; }
export type TimerAction = { type: 'start'; seconds: number } | { type: 'tick' } | { type: 'pause' } | { type: 'reset'; seconds: number };
export function timerReducer(state: TimerState, action: TimerAction): TimerState;
export const initialTimer = (seconds: number): TimerState => ({ secondsLeft: seconds, running: false });
```
- Rules: `start` → `{secondsLeft: seconds, running: true}`; `tick` → if running and >0 decrement; at 0 → `{secondsLeft:0, running:false}`; `pause` → running false; `reset` → `{secondsLeft: seconds, running:false}`.
